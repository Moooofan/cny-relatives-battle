# 酸度規範 v3 — 髒話全開

老闆指示（2026-09-04）：「全部都要寫的很難聽，幹、你他媽的、我去你的、去死這類的詞彙要多放。」
本規範**覆蓋** `docs/TONE_V2.md` 的用字尺度（v2 §2）；其他 v2 規則（機制對照、回嗆要跟著變狠、檢查清單）仍然有效。素材見 `docs/SAVAGE_REFERENCE.md`。

## 1. 用字尺度（放行清單）

**放行、而且要多用**：幹、幹你娘、幹你娘咧、他媽的、你他媽的、我去你的、去你的、去死、去死啦、死一死、機掰／雞掰、靠北、靠杯、白癡、白目、廢物、垃圾、滾、閉嘴、關你屁事、干你屁事、哭爸、笑死、北七、你是不是有病（口語，非指真實疾病）、老不死、死老頭、老東西、老太婆、死老太婆、老屁股、老番顛、活該、沒人要（老闆點名要多放年齡攻擊：對長輩罵老、罵沒用、罵沒人理）。台語音譯（幹恁娘、哩係咧供三小、三小）也放行。

**仍然禁止**（這是唯一的底線）：
- 種族／族群、性向、身障（智障、殘障、腦殘、瘸、聾、瞎）、真實疾病當笑話（癌、腫瘤、中風、失智、洗腎）。
- 性描寫、性騷擾式的話（對親戚身體的性暗示）。
- 真實政治人物／政黨、真實品牌人物。
- 家暴、外遇當梗。

## 2. 每種選項的髒話密度（強制）

| archetype | 密度 | 寫法 |
|---|---|---|
| landmine 踩雷 | **100%** 含至少一個重髒（幹／幹你娘／他媽的／去你的／去死／機掰），並且 **≥40% 含年齡攻擊**（死老頭／老東西／老太婆／老不死） | 最難聽、最直接，戳死對方最痛的點：「幹，妳兒子靠爸的事全家都知道，妳還敢問我薪水？」「去你的，你女兒離婚幾年了你倒是先講。」 |
| perfect 神回覆 | **≥70%** 含髒話（幹／靠北／他媽的／機掰 皆可） | 髒但機智，仍要把問題原封不動丟回去、讓全桌笑出來：「靠北，妳這麼會算，表哥年終幾個月妳怎麼不講？」 |
| backfire 反擊失敗 | **≥60%** 含髒話 | 罵了但罵歪：罵錯人、髒話用太用力反而冷場、自己先笑場、罵到自己。回嗆要寫出冷場或被反殺。 |
| deflect 四兩撥千斤 | **≥40%** 含輕髒（靠、幹嘛、笑死、哭爸） | 還是轉移／讚美／反問，但語氣痞：「靠，舅媽妳這麼關心，介紹個便宜房子啊。」 |
| meek 乖乖回答 | **≥40%** 含低聲髒話（幹……、靠……） | 仍是誠實無奈，但加一句嘟囔：「幹……四萬多啦，扣掉房租就沒了……」句尾保留「……」。 |

## 3. 回嗆（retort）也要髒

- perfect 之後：親戚吃癟＋罵回來：「幹，你這孩子嘴巴怎麼這麼賤」「他媽的沒大沒小」「（氣到講台語）幹恁娘咧」。
- landmine 之後：親戚炸了：「你他媽的給我滾出去」「去死啦你」「幹！叫你媽出來！」「明年不用他媽的來了」。阿嬤例外見 §5。
- backfire 之後：冷場＋反殺：「幹，你在講三小」「（全桌安靜）……白癡喔」。
- deflect／meek 之後：維持原本反應，可加一句碎念髒話。

## 4. 寫法檢查清單

1. 讀完會不會覺得「太髒了但好爽」？只有一句「幹」不算，要跟痛點綁在一起。
2. 每題 8 個選項至少 5 個有髒話；同一題不要 8 句都用「幹」開頭，輪替：幹／靠北／他媽的／去你的／機掰／去死／幹你娘／死老頭／老東西／老太婆。男性長輩（大伯、姑丈）用死老頭／老東西；女性長輩（三姑、三舅媽、陳太太）用老太婆／老東西／死老太婆；表姊用「老女人」「歐巴桑」；小表弟不用年齡攻擊（改用「死小孩」「小屁孩」「廢物小孩」）。
3. id、archetype、配方、題目攻擊句不動；選項 ≤30 字、回嗆 ≤30 字。
4. 同關主內同一句髒話組合（例：「幹你娘咧」）最多出現 12 次；輪替句型。
5. 底線清單（§1 禁止項）一條都不能碰。

## 5. 阿嬤例外（唯一的例外）

- 阿嬤題的 **perfect／deflect／meek 不對阿嬤罵髒話**；髒話只能指向別人（三姑、三舅媽、自己）：「幹，三姑夾的我才不吃，阿嬤妳夾的我全吞。」
- 阿嬤題的 **landmine／backfire 可以髒**（對阿嬤不耐煩到很難聽：「幹，妳很煩耶，不要一直夾」），機制上會被重罰，這是設計。
- 阿嬤的回嗆永遠不罵髒話：安靜、放下筷子、「……好」。
